# HBXC - Holo Bubbles XMPP Chat

A small, native Android XMPP chat client with a Holo Light look. Built and tested withp
[yax.im](https://yaxim.org/yax.im) server, but it should work with any standard XMPP server.
Runs on Android 4.0.3+ (API 15+).

# Features
- Create an account (in-band registration) or sign in; encrypted connection (STARTTLS) with certificate checks
- One-to-one chat with a contact list and presence
- Message Carbons: messages sent/received on your other devices show up here
- Server history (MAM) sync when the server supports it
- Group chats (MUC): join by address, browse public rooms, nicknames, rejoin on reconnect
- File and photo attachments via HTTP File Upload; images are previewed inline
- Notifications and a background connection service
- A built-in *Connection log* (menu) to help diagnose connection problems

Not included: end-to-end encryption (OMEMO), voice/video, message receipts.

# Compiling
Compile via terminal using `build.sh`
